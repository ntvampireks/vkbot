# Руководство по подключению бота к сообществу VK

Пошаговое руководство для подключения VK Bot к сообществу.

## Предварительные требования

- Аккаунт VK с правами администратора сообщества
- Сообщество (группа или публичная страница)
- Python 3.11+

---

## Шаг 1: Настройка сообщества VK

### 1.1 Перейдите к управлению сообществом

1. Откройте ваше сообщество VK
2. Нажмите **«Управление»** (в меню справа)

### 1.2 Включите работу с API

1. В разделе **«Настройки»** найдите блок **«Работа с API»**
2. Если API отключён — нажмите **«Включить»**

---

## Шаг 2: Создание токена доступа

1. В разделе **«Работа с API»** нажмите **«Создать токен»**
2. Выберите необходимые права:
   - ✅ **messages** — доступ к сообщениям (обязательно)
   - ✅ **groups** — доступ к группам (для получения ID)

3. Нажмите **«Создать»**
4. **Скопируйте токен** — он показывается только один раз!

> ⚠️ Сохраните токен в безопасное место. Никогда не коммитьте его в git.

---

## Шаг 3: Подключение Long Poll

Long Poll API позволяет получать сообщения в реальном времени.

1. В разделе **«Работа с API»** найдите блок **«Long Poll API»**
2. Нажмите **«Подключить»**
3. Запомните данные (понадобятся только для ручного тестирования):
   - **server** — адрес сервера
   - **key** — ключ доступа
   - **v** — версия API

> ℹ️ Бот использует эти данные internally через `VKClient`, вручную вводить их не нужно.

---

## Шаг 4: Настройка переменных окружения

### 4.1 Создайте файл `.env`

```bash
cp .env.example .env
```

### 4.2 Заполните обязательные переменные

```env
# Токен доступа сообщества (из Шага 2)
VK_GROUP_TOKEN=your_token_here

# Числовой ID сообщества (без минуса)
VK_GROUP_ID=12345678

# Имя бота для упоминаний (как написано в сообществе VK)
VK_BOT_NAME=Мой Бот
```

### Как найти ID сообщества

**Способ 1:** В URL управления

```
https://vk.com/edit?act=manage&group=12345678
                               ^^^^^^^^^^ это ID
```

**Способ 2:** В настройках сообщества

1. Управление → Настройки
2. Найдите **«Внутренний номер сообщества»** — это числовой ID

**Способ 3:** Через адресную строку

Если у сообщества есть адрес (например, `vk.com/mycommunity`), ID можно узнать через API:

```bash
curl "https://api.vk.com/method/groups.getById?group_id=mycommunity&access_token=YOUR_TOKEN&v=5.131"
```

## Шаг 5: Установка и запуск

### 5.1 Установите зависимости

```bash
pip install -r requirements.txt
```

### 5.2 Запустите бота

```bash
python -m bot.main
```

Ожидаемый вывод:

```
2026-06-20 15:30:00 - bot - INFO - Бот запущен...
```

---

## Шаг 6: Проверка работы

### 6.1 Настройте сообщения сообщества

1. В управлении сообществом перейдите в **«Сообщения»**
2. Включите **«Включено»** (сообщения сообщества)
3. Добавьте бота в список **«Служба поддержки»** (если требуется)

### 6.2 Протестируйте бота

1. Откройте диалог с сообществом в VK
2. Напишите: `привет`
3. Бот должен ответить приветствием

## Дополнительные настройки

### Настройка логирования

```env
# Путь к каталогу логов
LOG_DIR=logs

# Уровень логирования (DEBUG, INFO, WARNING, ERROR)
LOG_LEVEL=DEBUG
```

### Настройка лимитов

```env
# Максимум сообщений в истории диалога
MAX_HISTORY_MESSAGES=10

# Таймаут неактивности диалога (часы)
DIALOG_TIMEOUT_HOURS=24

# Максимум сообщений от пользователя за окно (защита от спама)
PER_USER_MAX_REQUESTS=10

# Размер окна для per-user лимита (секунды)
PER_USER_WINDOW_SECONDS=60
```

### Настройки отправки сообщений

```env
# Задержка перед отправкой (секунды)
MESSAGE_SEND_DELAY=0.5

# Задержка между попытками повторной отправки (секунды)
MESSAGE_RETRY_DELAY=1.0

# Таймаут VK API запросов (секунды)
MESSAGE_API_TIMEOUT=5

# Максимальная длина сообщения
MAX_MESSAGE_LENGTH=10000
```

## Возможные проблемы и решения

### Ошибка: `Access token access was denied`

**Причина:** Токен не имеет нужных прав

**Решение:** Пересоздайте токен с правами `messages`

### Ошибка: `Invalid group_id`

**Причина:** Неправильный ID сообщества

**Решение:** Убедитесь, что используете числовой ID без минуса

### Бот не отвечает на сообщения

**Причина:** Бот не упомянут в сообщении

**Решение:** В VK Bot отвечает только на сообщения, где он упомянут. Убедитесь, что:
1. Имя бота в `.env` точно совпадает с именем в сообществе VK
2. В сообщении есть упоминание бота (например, `@Мой Бот привет`)

### Сообщения не приходят

**Причина:** Long Poll не подключён или сообщество не разрешает боту читать сообщения

**Решение:**
1. Проверьте, что Long Poll подключён в разделе «Работа с API»
2. В настройках сообщества включите **«Сообщения»**
3. Убедитесь, что бот добавлен в **«Служба поддержки»**

## Ручное тестирование через curl

### Проверка токена

```bash
curl "https://api.vk.com/method/groups.getById?group_id=12345678&access_token=YOUR_TOKEN&v=5.131"
```

### Отправка сообщения вручную

```bash
curl -X POST https://api.vk.com/method/messages.send \
  -d "peer_id=12345678" \
  -d "message=Привет!" \
  -d "random_id=1" \
  -d "access_token=YOUR_TOKEN" \
  -d "v=5.131"
```
